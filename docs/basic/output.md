# Output

Dalam Python, **output** adalah hasil atau keluaran yang dihasilkan oleh program setelah menjalankan instruksi tertentu.

Output digunakan untuk menampilkan informasi, hasil perhitungan, nilai variabel, maupun pesan kepada pengguna.

## Menampilkan Output dengan print()
Python menyediakan fungsi bawaan print() untuk menampilkan output ke layar (terminal atau console).

```python
print("Hello World")
print("Belajar Python")
```

**Output:**
```text
Hello World
Belajar Python
```

## Menampilkan Nilai Variabel
Output juga dapat digunakan untuk menampilkan nilai yang tersimpan dalam variabel.
```python
nama = "Budi"
umur = 30

print(nama)
print(umur)
```
**output**
```text
Budi
30
```

## Menampilkan Hasil Perhitungan
Python dapat menampilkan hasil dari operasi aritmatika.
```python
a = 10
b = 5

print(a + b)
print(a * b)
```
**output**
```text
15
50
```
